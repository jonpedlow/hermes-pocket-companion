# Changelog

## 1.0.0 — 14 November 2026

- Discover local Hermes bots, avatars and conversation history. Stream replies and show tool activity.
- Copy Markdown messages and code blocks. Switch themes, fonts and profile accents. Dictate drafts in supported browsers.
- Send still PNG and JPEG images with bounded server-side validation and temporary preview cards. WebP and other file uploads are rejected.
- Install Pocket on Windows with a guided password prompt, a live gateway check and per-user startup and recovery. Follow the Hermes-assisted guide for a supervised installation.
- Install the browser app from a private HTTPS origin. Pocket needs a connection to its backend.
- Distribute source with an MIT licence for original work and notices for third-party components.

Verified on Windows and Android, including Android home-screen installation. Microphone transcription, iOS home-screen installation and Linux/macOS hosting remain unverified.
