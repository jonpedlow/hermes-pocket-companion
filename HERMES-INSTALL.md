# Install Pocket Companion for your owner

1. Read README.md, INSTALL.md, SECURITY.md and the Windows installer in this checkout. Confirm the owner’s intended source and release. Inspect the source locally before execution. Use the documented procedure with ordinary user permissions.
2. Identify the OS, Node/npm versions, the owner’s local Hermes home and Python, a running profile, checkout path and free loopback port. Check for an existing Pocket instance. If the OS is not Windows, explain the unverified status and stop before installation.
3. Explain the planned package downloads, local build, private settings folder, per-user sign-in task and selected loopback URL. Request the owner’s approval for these specific changes and any missing software. Keep other checkouts and services intact.
4. From a dedicated permanent checkout, run the documented installer in a **local interactive terminal visible to the owner**. If your tools cannot hand over the secure prompt, have the owner double-click **Setup Pocket.cmd** or run the documented PowerShell command locally. The owner types the password in that prompt and stores it in their own password manager. Never ask them to type a credential into chat, paste it as a shell argument, or share a verifier, session token or screenshot of secrets.
5. Read the installer outcome. Its native probe verifies the gateway before startup. Report the actual loopback address and task name. Have the owner sign in, select a profile and verify the expected conversation. Keep private messages and bot details out of install logs.
6. Offer optional phone access. Inspect existing Serve and Funnel configuration first. Explain the exact unused HTTPS endpoint and destination, obtain separate approval for the Tailscale change, then follow INSTALL.md. Never expose Hermes directly or enable Funnel. Have the owner confirm the HTTPS page from their phone and follow the relevant Add to Home Screen instructions.
7. Report the real local/mobile URLs, sign-in and recovery procedure, and any checks the owner must complete on-device. If a prerequisite fails, report its actual error and the smallest fix. Preserve the owner’s Hermes profiles, credentials, memory, permissions and existing infrastructure.
